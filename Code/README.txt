NocturNet supplementary files

config.json: configuration extracted from notebook source, including later CFG updates.
S1-S12 JSON files: source code and stored outputs grouped by experimental stage.
table_*.json: 18 individually extracted notebook tables (columns, index, data).
manifest.json: file inventory, provenance and availability.

These files were extracted without executing the notebook. Tables retain the precision of the stored displays. Single-seed, multi-seed, ensemble and adapted outputs are kept with their originating cells. Runtime-generated subject splits, raw data, model checkpoints and prediction arrays are not embedded in the supplied notebook and cannot be recovered from it.
